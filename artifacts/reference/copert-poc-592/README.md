# COPERT 5.9.2 reference experiment for UC-05

These artifacts record a preliminary proof of concept run with COPERT 5.9.2,
Tier 3, on Windows on 19 August 2026. The scenario uses the year 2024, a speed
of 70 km/h and the `Urban Off Peak` driving condition. It is a technical
experiment, not a scientific validation.

The run exercises technology selection for the four UC-05 macro-categories,
workbook inputs for stock, activity and driving conditions, CLI execution,
and conversion of `CO2_HOT` outputs to factors in gCO₂/vehicle-km.

It does not use the weighted ACI/ISPRA profiles or produce the full 10–70 km/h
factor matrix. The files serve as references for the COPERT input and output
formats.

## Test configuration

The input workbook contains eight illustrative technologies:

| UC-05 macro-category | COPERT technology |
|---|---|
| `CAR` | Passenger Cars, Petrol, Mini, Euro 6 d/e |
| `CAR` | Passenger Cars, Petrol PHEV, Medium, Euro 6 d/e |
| `CAR` | Passenger Cars, LPG Bifuel, Medium, Euro 6 d/e |
| `CAR` | Passenger Cars, CNG Bifuel, Medium, Euro 6 d/e |
| `TRUCK` | Heavy Duty Trucks, Diesel, Rigid ≤7.5 t, Euro VI D/E |
| `BUS` | Buses, Diesel, Urban Buses Midi ≤15 t, Euro VI D/E |
| `BUS` | Buses, Diesel Hybrid, Urban Buses Diesel Hybrid, Euro VI D/E |
| `MOTORCYCLE` | L-Category, Petrol, Motorcycles 4-stroke 250–750 cm³, Euro 5 |

Each row uses:

- stock: 1,000 vehicles;
- mean activity: 10,000 km;
- Urban Off Peak share: 100%;
- Urban Off Peak speed: 70 km/h;
- Urban Peak, Rural and Highway shares: 0%;
- gradient: 0%;
- HDT/BUS load: 50%;
- primary/secondary share for PHEV and hybrid buses: 64%/36%.

Temperatures in the workbook are test values, not a validated weather
configuration. The output considered here is `CO2_HOT`, which excludes
cold-start emissions.

## Deriving emission factors

The `CO2_HOT` sheet reports emissions in tonnes for the configured annual
activity. For each technology in this experiment:

$$
A_i = 1{,}000\;vehicles \times 10{,}000\;km = 10{,}000{,}000\;vehicle\text{-}km
$$

The corresponding factor is:

$$
EF_i = \frac{CO2\_HOT_i\;[t] \times 10^6\;[g/t]}
{10{,}000{,}000\;[vehicle\text{-}km]}
$$

For this configuration, the numerical value in gCO₂/vehicle-km is therefore
the value in tonnes divided by 10.

## Relationship to the proposed methodology

In the candidate method, each macro-category contains several COPERT
technologies with weights $w_{c,i}$ derived from ACI and ISPRA. Its mean factor
is:

$$
EF_c(v)=\sum_i w_{c,i}\,EF_i(v)
$$

The [fleet crosswalk](../../../docs/uc05-fleet-crosswalk-v0.1.md) describes how
the weights are constructed and their limitations.

## Limitations

- The experiment uses eight illustrative technologies with uniform stock and
  activity; it does not represent the traffic fleet in Baronissi.
- It tests only one speed, 70 km/h, and does not apply the ACI Salerno × ISPRA
  activity weights.
- It does not establish the scientific accuracy of the factors, measure
  atmospheric concentrations or estimate air quality.
- It must be repeated if the COPERT version, fleet, driving conditions or
  emissions boundary changes.

Operational use requires approved profiles, a versioned speed grid,
interpolation rules and a validation protocol.
